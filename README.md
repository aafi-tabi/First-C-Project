# First C++ Project

An interactive, console-based C++ program that simulates a day in the life of a user navigating through various activities and managing finances. The program combines structured programming, structs, arrays, loops, and functions to create a mini life simulator with shopping, dining, and recreational experiences.

## Features

- Struct-based data modeling for activities and finances
- Array and loop-driven simulation flow
- Interactive console menus for user choices
- Modular functions for each activity (shopping, dining, recreation)

## Tech Stack

- C++

## Getting Started

### Prerequisites
A C++ compiler such as `g++` (comes with most Linux/Mac systems, or install via [MinGW](https://www.mingw-w64.org/) on Windows).

### Build and Run

```bash
g++ main.cpp -o simulator
./simulator
```

On Windows (using MinGW):
```bash
g++ main.cpp -o simulator.exe
simulator.exe
```

## About

This was my first C++ project, built to practice core programming concepts — structs, arrays, loops, and functions — through a fun, interactive console simulation.
